# WorkBox · 给 AI 一张独立的 Windows 工作桌面

让桌面自动化在本地虚拟机里工作，把日常使用的主桌面留给你。

WorkBox 是运行在**本地 Windows Hyper-V 虚拟机**上的桌面自动化工具包。它为你的 Agent 或脚本提供观察画面、操作支持的窗口、运行有界面浏览器和取回结果的入口，适合把需要真实 Windows 桌面的任务放到一个单独的工作环境中。

它提供的是桌面执行工具，不是 AI 模型或托管平台。你选择并接入自己的 Agent 或脚本，明确任务权限，再由 WorkBox 在指定虚拟机内执行。

**[准备环境，取得第一张来宾桌面截图 →](docs/INSTALL.zh-CN.md)**

## 适合哪些工作

- **开发 Agent 或自动化脚本**：先在专用 Windows 桌面里验证观察、输入与结果读取，不必让实验直接操作日常主桌面。
- **验证网页交互**：在来宾的有界面浏览器中打开页面、填写测试表单、检查窗口和弹窗，再保存本地证据。
- **复用同一任务的登录状态**：明确项目、用户和站点后，可选择加密保存浏览器状态，让后续同范围任务尝试从已有状态接续。

默认原生窗口支持范围是记事本和计算器；其他 App 需要另行接入与验证。能用命令或 API 完成的任务，仍优先使用那些入口。

## 为什么用起来方便

| 能力 | 带来的实际帮助 |
| --- | --- |
| 把操作目标固定在来宾桌面 | 正常后台执行路径把键鼠动作留在 VM 内，减少与宿主日常操作争用；本人打开控制台仍是可见交互。 |
| 一次任务，统一取得操作权 | 同一 VM 的协作调用者通过共享租约串行执行整段任务，避免两个任务同时点击同一桌面。 |
| 原生桌面动作使用请求与回执 | 可以查看新截图与结果；超时先查原请求，不必猜测后盲目重复输入。 |
| 网页视口随窗口变化 | 浏览器会话入口适配自己的新窗口和弹窗，避免用固定网页尺寸掩盖实际显示边界。 |
| 按范围选择保存登录状态 | 同项目、同用户、指定 HTTPS 站点的状态在本机加密保存，减少有条件可复用场景中的重复准备；默认仍为匿名新会话。 |

## 从准备环境到核对结果

1. **准备专用工作桌面**：按安装指南配置合法 Windows VM、普通来宾用户及本机路径。
2. **运行一个有边界的任务**：调用示例或接入自己的脚本；整个任务使用该 VM 的同一租约。
3. **看结果，再接下一步**：核对新画面和实际产物，关闭自己的浏览器会话，再释放操作权。

完成安装后，在仓库根目录用 PowerShell 7 取得第一张截图：

```powershell
./examples/observe.ps1 -ConfigPath '<你的私有配置绝对路径>' -EvidenceDirectory '<本次证据目录绝对路径>'
```

接下来可试[有界面浏览器示例](examples/browser.ps1)，或按[使用指南](docs/USAGE.zh-CN.md)完成记事本输入、超时取证和按范围保存状态。浏览器依赖须先按安装指南配置。

## 当前阶段与证据

**当前为开源预览版，尚非稳定版。** 原本机实现已验证部分桌面/网页操作、窗口与弹窗适配、同范围合成 cookie/localStorage 恢复和跨项目/用户隔离；原控制台入口也已观察到一次完整进入既有来宾会话。便携候选已通过源码、局部功能、脱敏、归档一致性及独立审查。开放源码供检查、学习和有边界的试用，不把公开发布当作跨机验收。

这些证据不等于新机器已验收。跨机安装、便携入口真实开窗、生产网站登录、冷启动与注销后登录仍待验证；只读预检或合成版本矩阵用例不能代替这些验收。网站会话仍可能到期，状态复用不保证免登，也不绕过认证。

使用环境为 Windows Hyper-V；[兼容性矩阵](docs/COMPATIBILITY.zh-CN.md)分别说明宿主、来宾、桌面和可选浏览器条件。Windows 10 桌面通道仍可按条件评估，不能套用浏览器的 Windows 11+ 条件一并排除。当前运行实证仅来自本机，不代表所有 Windows 版本通过。

查看完整的[验证与限制](docs/VERIFICATION.md)、[安全说明](SECURITY.md)和[排障方法](docs/TROUBLESHOOTING.zh-CN.md)。新浏览器会话不是权限沙箱，网络访问仍受任务授权约束。
