# WorkBox 产品介绍

[English](INTRODUCTION.en.md) · [项目首页](../README.zh-CN.md)

以下为可用于发布公告的介绍稿，当前阶段仍为预发布定向试用；这份文案不表示已经公开发布或完成跨机验收。

## 一句话

WorkBox 给 AI 一张独立的 Windows 工作桌面：把支持的桌面与网页操作放到本地 Hyper-V 虚拟机里，并提供可检查的任务结果。当前为预发布试用版。

## 短段落

开发 Agent 时，需要真实桌面的任务不必直接落在日常主桌面上。WorkBox 是一个本地 Windows Hyper-V 桌面自动化工具包，让你自己的 Agent 或脚本在指定 VM 中观察画面、操作支持的窗口、使用有界面浏览器，再取回截图和回执。共享租约让协作任务轮流操作；按项目、用户和站点选择保存的加密状态，可用于后续同范围接续。当前处于预发布定向试用，跨机安装和生产网站登录仍待验证。

## 完整短介绍

### 给 AI 一张独立的 Windows 工作桌面

有些自动化任务需要看到真正的窗口、输入文字、处理网页弹窗，再检查最后的结果。WorkBox 把这些工作放进本地 Windows Hyper-V 虚拟机，为你自己的 Agent 或脚本提供一套桌面执行入口。它不是 AI 模型或托管服务，模型选择和任务授权仍由你掌握。

在正常后台调用路径中，操作目标留在来宾桌面，减少与宿主日常工作的争用。多个协作任务共用一张桌面时，通过同一租约轮流完成整段操作；原生桌面请求保留回执，超时先找原结果，避免盲目重复输入。你可以从观察截图开始，再试记事本、计算器，或在可选有界面浏览器中验证页面与表单。

浏览器会话入口让网页视口跟随窗口，并适配自己的新窗口和弹窗。需要接续同一范围的任务时，可显式按项目、用户和 HTTPS 站点加密保存状态；默认仍新建匿名会话。保存状态不等于永久免登，网站认证和会话到期规则照常适用。

WorkBox 当前为预发布定向试用候选。原本机已有部分桌面、网页、显示适配和合成状态隔离的验证，便携候选通过独立审查；新机器安装、生产网站登录和冷启动等场景仍待实际试用。它适合愿意配置本地 Windows VM、希望验证桌面自动化的开发者和技术团队。

目标环境为 Windows Hyper-V；[兼容性矩阵](COMPATIBILITY.zh-CN.md)区分宿主、来宾和桌面/浏览器通道。现有运行实证仅来自本机，不代表所有 Windows 版本通过。
