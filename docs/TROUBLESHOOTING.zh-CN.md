# 排障

版本问题先回[兼容性矩阵](COMPATIBILITY.zh-CN.md)，分别核宿主/来宾与桌面/浏览器，不因一个通道不支持就误判所有通道。

| 现象 | 核查与有界下一步 |
| --- | --- |
| 脚本执行被阻止 | 核目标普通用户的有效策略、语言模式及文件签名/来源；管理员 PSDirect 能执行不等于该用户能执行。按正常策略流程解决，不自动削弱机器策略；unknown 补证前不继续依赖步骤。 |
| Windows 10 上浏览器预检拒绝 | 当前浏览器候选范围是 Windows 11+ / Server 2019+；桌面通道仍可按 Windows 10 1607 / build 14393+ 条件单独评估，不静默换旧浏览器。 |
| Home / Education 的版本判定有疑问 | Home 宿主不支持所需 Hyper-V，但 Home 来宾另核实际条件；Education 按 Hyper-V/PSDirect 实际能力判定。 |
| 位数、Server Core或缺桌面组件 | 本候选要求 x64 与真实交互桌面，Server Core/ARM64/x86不在范围；32位父进程须经可用入口转换为原生64位后再核，不直接运行宿主工具；不靠放宽窗口白名单解决。 |
| PSDirect 连不上 | 核精确 VM ID/名称/运行状态、宿主管理权限、来宾管理员凭据，不猜测重建/重启。 |
| 无 ready 或身份过期 | 核普通用户交互会话、计划任务结果、源哈希及旧 worker 是否仍活着；任务启动返回不代表就绪。 |
| 安装报目录/任务存在 | 停下核原部署，安装器故意不覆盖；部分安装由管理员仅清本次确定对象后再试。 |
| 租约繁忙 | 最多等待配置上限，结束本次占用请求；不杀持有者、不删锁。 |
| 请求超时/仍 pending | 查原 ID，不重发输入；核 worker 和原结果后再操作。 |
| 原生点击拒绝 | 重观察新截图，核前台、身份、遮挡和坐标，不放宽白名单来点击权限界面。 |
| 浏览器起不来 | 核 Node/Playwright 精确版本、普通用户交互登录、自定义缓存和计划任务结果；服务必须先设置缓存变量再加载 Playwright。 |
| NAT 变化后连接失败 | 核实际两侧 IP、监听者与窄防火墙规则；管理员按精确地址更新，不允许任意远端。 |
| 右/下边缘裁剪 | 对照来宾屏幕、窗口外尺寸和网页内尺寸。新 context 用 `viewport: null`，在真实来宾显示内调整窗口并看新桌面图；放大模拟 viewport 不算修显示。 |
| 评估 VM 每小时关机 | 按微软条款核激活/到期，使用合法许可证；不绕过到期限制。 |

不要公开原始浏览器错误、完整命令行、带秘密路径 URL、截图、cookie 或用户日志。诊断留本地最小时间点与身份通过/失败。单路失败时保留任务目标，在原授权内评估命令/API、无头、独立桌面等价路线；权限拒绝不能被视为绕过授权。
